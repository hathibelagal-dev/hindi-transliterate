# Usage Examples

This folder contains examples of how to use the `@indic-tools/hindi-transliterate` package in different environments.

## 1. Vanilla JavaScript

To run the vanilla JavaScript example, use Node.js:

```bash
node examples/vanilla/index.js
```

## 2. React

The `react-example` folder contains a basic React component using both the `useTransliterate` hook and the `Transliterate` component. 

### How to use in your React project:

1.  **Install the package:**
    ```bash
    npm install @indic-tools/hindi-transliterate
    ```

2.  **Import and use:**
    ```javascript
    import { useTransliterate, Transliterate } from '@indic-tools/hindi-transliterate/react';
    ```

Check `examples/react-example/App.js` for a full integration example.
